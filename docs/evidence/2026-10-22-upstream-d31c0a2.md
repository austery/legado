## Compatibility decisions

Preserve both audio spectrum suites, renaming the local class without weakening
assertions. Retain native bridge lifecycle tests and use upstream's equivalent
scope-owned object registration. Preserve the iOS host's prohibition on removing
unpublished extension-owned temporary files while adopting active notifications and
text-slot pickup. Restore imports needed by the retained audio source-return path.

An unchanged audio regression failed when upstream SingleTask navigation removed
an intervening details page. Retain Standard launch specifically for AudioPlay to
preserve nested source-return targets; other upstream launch rules remain. Clean
local pending results and catalog handlers when SingleTask removes other entries.

The owner separately approved both compatibility additions on 2026-10-22:

- Migrate legacy desktop Preferences only when the JSON file is absent. Preserve
  raw string values and old storage; do not guess types or overwrite existing JSON.
  Persist even an empty migration. Failed reads, invalid JSON and failed initial
  persistence must not silently start with empty settings. Existing JSON remains
  authoritative on restart, including explicitly removed keys.
- WebDAV backup upload must either complete or throw. A network/authentication
  preflight before export cannot certify an upload after compression. Missing
  connectivity/authorization and transport failures cannot report remote-only
  backup success. The caller's existing local-copy fallback remains unchanged.

## Evidence and recovery limits

The original integration candidate `48863d0e1` passed both framework links, original
UI compilation, JVM suites, Kotlin/Native suites, Swift engine network/cache checks,
ordinary product tests and separate interruption/offline-restart tests. Its review
found the two compatibility issues above; those green tests did not certify them.
New focused tests cover migration/restart/failed writes/unreadable JSON and backup
network loss/cleared authorization/transport failure/completed upload.

Final-head execution and independent review are recorded in the PR; earlier-head
results are not substitutes. Local detailed logs are retained under
`docs/evidence/upstream-d31c0a2/` in the primary checkout.

No live provider, physical device, signing/distribution or full desktop GUI
acceptance is claimed. Legacy preference storage is retained for recovery, but a
code rollback does not synchronize settings subsequently changed in JSON back to
legacy storage. No database migration is introduced. The origin/master mirror,
C1 policy and runner settings are outside this integration.
